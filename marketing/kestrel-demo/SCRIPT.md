# Kestrel demo: voiceover script (about 45 seconds)

Read it slowly and warmly, like you're showing a friend. Pause where you see ·. It's fine to say it in your own words.

Each line matches a part of the edited video. The tool (`scripts/marketing/demo-video.mjs`) cuts your recording in this order.

| Video | You say |
| --- | --- |
| **0:00 – login screen** (“OPS secure console”) | “Getting your pages onto Google is slow, boring work. · So I built a team of AI agents to do it for me.” |
| **0:03 – Mission control** (the agent network, token burn) | “This is mission control. · Each circle is an agent: one finds pages Google hasn’t indexed, one writes, one reviews, one publishes.” |
| **0:09 – Indexing team** (agent cards) | “Eleven agents working as one team. · And anything important waits for my approval first.” |
| **0:15 – Settings** (token budgets) | “I set a daily budget, · and they spend it on the pages that matter most.” |
| **0:20 – Indexing progress** (34 / 40 / 24) | “Thirty-four pages confirmed indexed by Google, · forty more waiting.” |
| **0:26 – Impressions** (29.7k, +29%) | “In the last four weeks: almost thirty thousand impressions, · up twenty-nine percent, · and clicks up sixty.” |
| **0:33 – Pages changed** (the table) | “Every page it touched, tracked. · No guessing.” |
| **0:38 – end card** | “Want an agent like this for your website? · It’s called Kestrel. · Link in bio.” |

## Recording tips

- Use your phone’s voice recorder, 15 cm from your mouth, in a room with curtains or a wardrobe full of clothes (it soaks up echo).
- Record the whole script in one go; do two or three takes and keep the best.
- Leave one second of silence at the start: the tool uses it to learn your background noise.
- Save it as `voice.m4a` (or .mp3/.wav) in this folder.
